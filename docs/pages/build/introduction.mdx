**EAS Build** is a hosted Expo Application Services (EAS) service that builds app binaries (also called [standalone apps](/more/glossary-of-terms/#standalone-app)) for your Expo and React Native projects.

EAS Build makes building your apps for distribution simple and easy to automate by providing defaults that work well for Expo and React Native projects out of the box, and by handling your app signing credentials for you (if you wish). It also makes sharing builds with your team easier than ever with [internal distribution](/build/internal-distribution/) (using [ad hoc](/build/internal-distribution/) and/or enterprise "universal" provisioning), deeply integrates with EAS Submit for app store submissions, and has first-class support for the [`expo-updates`](/build/updates/) library.

EAS Build is also designed to work for any native project, whether or not you use Expo and React Native. It's the fastest way to get from `npx create-expo-app` or `npx @react-native-community/cli@latest init` to app stores.

## Quick start

> **info** The `eas` commands below require EAS CLI. See [How to install EAS CLI](/eas/cli/#installation) for more information.

To build your app, run the following command:

<Terminal cmd={['$ eas build --platform all']} />

This command sends your project to EAS Build and produces installable binaries for Android and iOS. You can also build for one platform at a time by passing in `--platform android` or `--platform ios` as desired. For complete setup instructions, see [Create your first build](/build/setup/).

## Key features

- Cloud builds for Android and iOS with consistent environments
- Automatically provision and manage app signing credentials or use your own
- Share [internal distribution](/build/internal-distribution/) builds with a URL
- Automate builds with [build profiles](/build/eas-json/#build-profiles) in **eas.json** (named sets of build settings) and integrations with [EAS Workflows](/eas/workflows/get-started/) or [CI pipelines](/build/building-on-ci/)
- Auto-submit successful builds to app stores via [`--auto-submit`](/build/automate-submissions/) and EAS Submit
- First-class [`expo-updates` integration](/build/updates/) with per-profile channels and [runtime version](/eas-update/runtime-versions/) guidance
- Reuse [development builds](/develop/development-builds/introduction/) across your team. When two team members run `eas build:dev` and the project fingerprint matches, the existing build is downloaded from EAS instead of creating a new one
- Faster builds via [dependency caching and custom cache paths](/build-reference/caching/)
- Install builds and updates on devices with [Expo Orbit](https://expo.dev/orbit)

## Frequently asked questions

<FAQ>

<Collapsible summary="How do I share builds with my team before submitting to app stores?">

Use [internal distribution](/build/internal-distribution/) to share builds with a URL. Set `"distribution": "internal"` in your [build profile](/build/eas-json/#build-profiles) in **eas.json** to generate installable Android Package (APK) files for Android or [ad hoc builds](/build/internal-distribution/) for iOS.

</Collapsible>

<Collapsible summary="Can I use EAS Build with existing React Native projects?">

Yes. EAS Build works with existing React Native projects created with `npx react-native init` or similar tools. See [Overview of using Expo with existing React Native apps](/bare/overview/) for more information.

</Collapsible>

<Collapsible summary="Does EAS Build handle app signing credentials?">

Yes. EAS Build can generate and manage Android [keystores](/app-signing/app-credentials/#android), iOS [provisioning profiles](/app-signing/app-credentials/#ios) and [distribution certificates](/app-signing/app-credentials/#ios), or use credentials you provide. See [App signing credentials](/app-signing/app-credentials/) for more information.

</Collapsible>

<Collapsible summary="Can I run builds locally instead of in the cloud?">

Yes. Use [local builds](/build-reference/local-builds/) with `eas build --local` to run builds on your machine. This is useful for debugging or for security policies that require local builds.

</Collapsible>

<Collapsible summary="Can I use EAS Build with EAS Workflows or CI pipelines?">

Yes. EAS Build integrates with [EAS Workflows](/eas/workflows/get-started/) using the `build` job type. Add a build job to your workflow configuration, for example:

```yaml
jobs:
  build_ios:
    type: build
    params:
      platform: ios
```

The build job supports builds for both platforms or conditional builds based on the branch:

```yaml
jobs:
  build:
    type: build
    params:
      platform: all
      profile: ${{ github.ref_name == 'main' && 'production' || 'preview' }}
```

For more information and other usage examples, see the [EAS Workflows build job](/eas/workflows/pre-packaged-jobs#build).

EAS Build supports [builds from GitHub](/build/building-from-github/) and [building on CI](/build/building-on-ci/) with any provider.

</Collapsible>

<Collapsible summary="What build server infrastructure does EAS Build use?">

Android builds run on Linux runners hosted in Google Cloud Platform, and iOS builds run on macOS runners hosted in Expo's macOS cloud. See [Build server infrastructure](/build-reference/infrastructure/).

</Collapsible>

</FAQ>

import React, { useState, useEffect } from 'react';
import {
  StyleSheet,
  Text,

} from 'react-native';

import { Question, LifelineType, UserProfile } from '../types/game';
import { GlassCard } from '../components/GlassCard';
import { CouncilModal } from '../components/CouncilModal';
import { AttioCRM } from '../services/AnalyticsAndCRM';
import { MonetizationService } from '../services/MonetizationService';

const LADDER_REWARDS = [100, 200, 300, 500, 1000, 2000, 4000, 8000, 16000, 32000, 64000, 125000, 250000, 500000, 1000000];

const SAMPLE_QUESTION: Question = {
  question_id: 'sp_q_5082',
  category: 'Biblical History & Events',
  difficulty_level: 5,
  story_context: 'During the reign of King Hezekiah, Jerusalem faced an imminent siege by the Assyrian army under Sennacherib.',
  prompt: 'Which strategic engineering project did Hezekiah undertake to secure the city\'s water supply prior to the siege?',
  options: [
    { id: 'A', text: 'Rebuilding the Eastern Water Gate' },
    { id: 'B', text: 'Tunneling through solid rock from Gihon Spring to Siloam' },
    { id: 'C', text: 'Constructing deep reservoirs in the Kidron Valley' },
    { id: 'D', text: 'Diverting the Jordan River into northern cisterns' },
  ],
  correct_option_id: 'B',
  scripture_proof: '2 Chronicles 32:30',
  reasoning_explanation: 'Hezekiah blocked the upper outlet of the Gihon spring and channeled the water straight down to the west side of the City of David.',
  lifeline_data: {
    scriptural_hint: 'Focus on the underground channel leading directly to Siloam.',
    fifty_fifty_remove: ['A', 'D'],
  },
};

const MOCK_USER: UserProfile = {
  id: 'usr_88392',
  email: 'leader@ministry.org',
  name: 'David Pastor',
  isPro: false,
  streakCount: 7,
  pearlsBalance: 1200,
};

export const QuizArenaScreen: React.FC = () => {
  const [questionIndex, setQuestionIndex] = useState<number>(4);
  const [disabledOptions, setDisabledOptions] = useState<string[]>([]);
  const [usedLifelines, setUsedLifelines] = useState<Record<LifelineType, boolean>>({
    scriptural_hint: false,
    fifty_fifty: false,
    verse_swap: false,
    community_wisdom: false,
  });
  const [showCouncilModal, setShowCouncilModal] = useState<boolean>(false);
  const [activeHint, setActiveHint] = useState<string | null>(null);

  useEffect(() => {
    AttioCRM.syncUserToAttio(MOCK_USER, 'ASCENT_RUN_STARTED', { levelIndex: questionIndex });

    if (questionIndex === 4 || questionIndex === 9) {
      setShowCouncilModal(true);
    }
  }, [questionIndex]);

  const handleAnswerSelection = async (selectedId: string) => {
    if (selectedId === SAMPLE_QUESTION.correct_option_id) {
      await Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success);
      if (questionIndex < LADDER_REWARDS.length - 1) {
        setQuestionIndex(prev => prev + 1);
        setDisabledOptions([]);
        setActiveHint(null);
      } else {
        Alert.alert('Ascent Master!', 'You reached the peak of wisdom!');
      }
    } else {
      await Haptics.notificationAsync(Haptics.NotificationFeedbackType.Error);
      await AttioCRM.syncUserToAttio(MOCK_USER, 'ASCENT_RUN_FAILED', { failedAtQuestion: questionIndex + 1 });
      await MonetizationService.triggerPaywall('second_chance_revive');
      
      Alert.alert('Ascent Ended', `Proof: ${SAMPLE_QUESTION.scripture_proof}. ${SAMPLE_QUESTION.reasoning_explanation}`);
    }
  };

  const executeFiftyFifty = () => {
    if (usedLifelines.fifty_fifty) return;
    Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    setDisabledOptions(SAMPLE_QUESTION.lifeline_data.fifty_fifty_remove);
    setUsedLifelines(prev => ({ ...prev, fifty_fifty: true }));
  };

  const executeHint = () => {
    if (usedLifelines.scriptural_hint) return;
    Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    setActiveHint(SAMPLE_QUESTION.lifeline_data.scriptural_hint);
    setUsedLifelines(prev => ({ ...prev, scriptural_hint: true }));
  };

  const handleAcceptCouncilOffer = async () => {
    setShowCouncilModal(false);
    const guaranteedPearls = LADDER_REWARDS[questionIndex - 1] || 500;
    
    await AttioCRM.syncUserToAttio(MOCK_USER, 'COUNCIL_OFFER_ACCEPTED', { cashedOutPearls: guaranteedPearls });
    Alert.alert('Banker Offer Accepted', `You cashed out with ${guaranteedPearls} Pearls!`);
  };

  return (
    <LinearGradient colors={['#080A15', '#161B3D', '#080A15']} style={styles.container}>
      <StatusBar style="light" />
      <SafeAreaView style={styles.safeArea}>
        
        {/* HUD Navigation Header */}
        <View style={styles.headerContainer}>
          <View style={styles.badgeContainer}>
            <Text style={styles.badgeText}>CHERUBIM LEAGUE</Text>
          </View>
          <View style={styles.rewardContainer}>
            <Text style={styles.rewardLabel}>QUESTION {questionIndex + 1} VALUE</Text>
            <Text style={styles.rewardValue}>{LADDER_REWARDS[questionIndex]} Pearls</Text>
          </View>
        </View>

        {/* Dynamic Lifelines Action Bar */}
        <View style={styles.lifelinesContainer}>
          <TouchableOpacity 
            style={[styles.lifelineButton, usedLifelines.fifty_fifty && styles.lifelineDisabled]} 
            onPress={executeFiftyFifty}
            disabled={usedLifelines.fifty_fifty}>
            <Text style={styles.lifelineText}>50:50</Text>
          </TouchableOpacity>
          <TouchableOpacity 
            style={[styles.lifelineButton, usedLifelines.scriptural_hint && styles.lifelineDisabled]} 
            onPress={executeHint}
            disabled={usedLifelines.scriptural_hint}>
            <Text style={styles.lifelineText}>Verse Hint</Text>
          </TouchableOpacity>
        </View>

        {/* Central Scenario Glass Container */}
        <Animated.View entering={FadeInUp.duration(500)}>
          <GlassCard>
            <Text style={styles.categoryText}>{SAMPLE_QUESTION.category.toUpperCase()}</Text>
            {SAMPLE_QUESTION.story_context && (
              <Text style={styles.storyText}>{SAMPLE_QUESTION.story_context}</Text>
            )}
            <Text style={styles.promptText}>{SAMPLE_QUESTION.prompt}</Text>
            
            {activeHint && (
              <View style={styles.hintContainer}>
                <Text style={styles.hintText}>📖 {activeHint}</Text>
              </View>
            )}
          </GlassCard>
        </Animated.View>

        {/* Multiple Choice Selection Grid */}
        <View style={styles.optionsContainer}>
          {SAMPLE_QUESTION.options.map((option, idx) => {
            const isDisabled = disabledOptions.includes(option.id);
            return (
              <Animated.View key={option.id} entering={FadeInDown.delay(idx * 80)}>
                <TouchableOpacity
                  activeOpacity={0.8}
                  disabled={isDisabled}
                  style={[styles.optionButton, isDisabled && styles.optionDisabled]}
                  onPress={() => handleAnswerSelection(option.id)}>
                  <Text style={styles.optionPrefix}>{option.id}</Text>
                  <Text style={styles.optionText}>{option.text}</Text>
                </TouchableOpacity>
              </Animated.View>
            );
          })}
        </View>

        {/* High-Stakes Banker Modal Component */}
        <CouncilModal
          visible={showCouncilModal}
          currentQuestionNumber={questionIndex + 1}
          offeredPearls={LADDER_REWARDS[questionIndex - 1] || 500}
          onAccept={handleAcceptCouncilOffer}
          onDecline={() => setShowCouncilModal(false)}
        />

      </SafeAreaView>
    </LinearGradient>
  );
};
